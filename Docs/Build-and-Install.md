# Build and Install

Things you need to know beyond `project.yml` to get a working widget on the desktop.

## Project generation

`OfficeClock.xcodeproj` is generated by XcodeGen and is git-ignored. Edit
`project.yml`, never the `.xcodeproj`.

```sh
brew install xcodegen
xcodegen generate
```

## Code signing

- No Apple ID is signed in to Xcode on the development machine, so automatic
  signing fails ("No Account for Team"). The project uses **manual signing with
  the local "Apple Development" certificate** and no provisioning profile. This
  works because the only entitlement is App Sandbox.
- The certificate's name ends with `(TTU92888H4)`, but that is **not** the team
  ID. The team ID is the certificate's `OU` field (`N6V3488B33`). To check it:

  ```sh
  security find-certificate -c "Apple Development: Keijiro" -p | openssl x509 -noout -subject
  ```

- A widget extension must be sandboxed, or the system won't load it.

## Build, install and refresh

The widget host caches each extension's descriptor (supported sizes and so on).
It may also pick up a stale copy, so use this full sequence whenever you install
a change that affects the widget:

```sh
LSR=/System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister
APP=build/Build/Products/Release/OfficeClock.app

# 1. Bump CURRENT_PROJECT_VERSION in project.yml, then:
xcodegen generate
xcodebuild -project OfficeClock.xcodeproj -scheme OfficeClock -configuration Release -derivedDataPath build build

# 2. Unregister the copy in build/ (each build registers it automatically).
pluginkit -r $APP/Contents/PlugIns/OfficeClockWidget.appex
$LSR -u $APP

# 3. Install to ~/Applications and register it.
pkill -x OfficeClock
rm -rf ~/Applications/OfficeClock.app && cp -R $APP ~/Applications/
$LSR -f ~/Applications/OfficeClock.app

# 4. Restart the widget host processes.
killall chronod NotificationCenter

# Check: exactly one line, pointing at ~/Applications.
pluginkit -m -p com.apple.widgetkit-extension -v -A -D | grep -i officeclock
```

If the widget still shows old content or options, remove it from the desktop
and add it again. Logging out and back in is the last resort.

The `CoreSimulator is out of date` message that `xcodebuild` prints on this
machine is harmless for a macOS build.
